# Root Pathway Module Admin Portal Requirements

## Description

Build the Root Pathway Module Admin Portal, a modular, visual, non-technical admin system for configuring wellness pathways inside Auryn.

The system must enable admins to build and manage sophisticated wellness journeys without developer intervention, including:

- wellness categories
- guided decision funnels
- education engine
- product contribution logic
- personalization workflows
- optimization rules
- AI instruction management
- physician governance
- analytics and self-learning

## Core Experience Goals

- Highly visual admin UX
- Drag-and-drop orchestration
- Modular and reusable architecture
- Simple for non-technical admins
- Scalable and extensible
- Governed AI and physician approval workflows

## Most Important Principle

Everything should be:

- Modular
- Reusable
- Editable
- Visual
- Scalable
- Non-technical user friendly

## Priority

High

## Admin Capabilities

Admins can:

- Create and manage pathways
- Configure funnel logic
- Define decision trees
- Manage education content
- Assign products and ingredients
- Configure optimization rules
- Edit AI instructions
- Set personalization rules
- Review analytics
- Approve AI suggestions
- Handle physician review workflows
- Access activity logs and audit history

## Product Examples

- Drag/drop funnel builder: admin config tool
- Education cards CRUD: admin content management
- Optimization IF/THEN rules: admin logic builder
- AI instruction editor: admin behavior controls
- Physician review statuses: governance workflow
- Self-learning approvals: admin moderation system

## Frontend Stack

- Framework: Next.js 15 with React
- Language: TypeScript
- UI: TailwindCSS and ShadCN
